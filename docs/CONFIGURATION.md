# Forest OS Configuration System (conf.sh)

## Overview

Forest OS includes a comprehensive Terminal User Interface (TUI) configuration system, `conf.sh`, modeled after the Linux kernel's `menuconfig` system. This tool provides an interactive way to configure build options, enable/disable features, and customize the operating system behavior.

`★ Insight ─────────────────────────────────────`
**Linux-Style Configuration Excellence:**
- **Professional TUI Interface**: Full-screen interactive menus with keyboard navigation
- **Hierarchical Menu System**: Organized categories matching kernel development standards  
- **Dependency Management**: Automatic handling of feature dependencies and conflicts
- **Live Validation**: Real-time checking of configuration consistency
`─────────────────────────────────────────────────`

## Features

### 🎯 **Core Capabilities**
- **Interactive TUI**: Full-screen terminal interface with arrow key navigation
- **Hierarchical Menus**: Organized configuration categories and subcategories
- **Multiple Data Types**: Boolean flags, choice selections, and integer values
- **Dependency Tracking**: Automatic dependency resolution and validation
- **Configuration Persistence**: Save/load configurations from files
- **Build Integration**: Direct generation of build system configuration files

### 🛠️ **Configuration Categories**

1. **General Setup** - Architecture, boot mode, build type
2. **Processor** - SMP, ACPI, APIC, HPET support  
3. **Memory Management** - Paging, protection, allocators
4. **File Systems** - VFS, file system drivers
5. **Graphics** - Display drivers, framebuffer support
6. **Networking** - Network stack, protocol support
7. **Security** - Security features and protections
8. **Debug Options** - Debugging and diagnostic features
9. **Hardware Support** - Device drivers and hardware interfaces
10. **Audio Support** - Sound subsystem and audio drivers

## Usage

### Interactive Configuration

```bash
# Launch interactive configuration
./conf.sh

# Configuration with help
./conf.sh
# Press 'H' for help on any option
```

### Command Line Operations

```bash
# Load default configuration
./conf.sh --defaults

# Generate build configuration
./conf.sh --generate

# Save configuration
./conf.sh --save myconfig.conf

# Load configuration
./conf.sh --load myconfig.conf

# Create default config file
./conf.sh --defconfig
```

### Keyboard Controls

| Key | Action |
|-----|--------|
| `↑` `↓` | Navigate menu items |
| `Enter` | Select/modify option |
| `Space` | Toggle boolean options |
| `Y` | Enable boolean option |

| `H` | Show help for current item |

| `L` | Load configuration |
| `ESC` | Exit menu/application |

### Menu Types

1. **Boolean Options**: `[*]` enabled, `[ ]` disabled
2. **Choice Options**: `(value)` current selection
3. **Integer Options**: `(number)` numeric value
4. **Submenus**: `->` indicates submenu

## Configuration File Format

### .forestos_config Format

```bash
#
# Forest OS Configuration
# Generated by conf.sh on Mon Dec 23 03:10:15 UTC 2024
#

# Choose the target architecture for Forest OS
CONFIG_BUILD_ARCH=32

# Select the boot firmware interface  
CONFIG_BUILD_BOOT_MODE=bios

# Select compilation optimization and debug level
CONFIG_BUILD_TYPE=debug

# Enable support for multiple CPU cores
CONFIG_ENABLE_SMP=y

# Enable ACPI power management and device enumeration
CONFIG_ENABLE_ACPI=y
```

### build-config.mk Format

```makefile
# =============================================================================
# FOREST OS BUILD CONFIGURATION (Generated by conf.sh)
# =============================================================================

# Build Configuration
ARCH := 32
BOOT_MODE := bios
BUILD_TYPE := debug

# Feature Flags
ENABLE_SMP := yes
ENABLE_ACPI := yes
ENABLE_GRAPHICS := yes

# Compiler Feature Flags
FEATURE_FLAGS := -DENABLE_SMP -DENABLE_ACPI -DENABLE_GRAPHICS

# Build Options
OPTIMIZATION_LEVEL := 2
```

## Dependency System

The configuration system automatically manages dependencies between options:

### Dependency Types

1. **Simple Dependencies**: Option A requires Option B
2. **Conditional Dependencies**: Option A requires Option B = value
3. **Mutual Exclusion**: Options that cannot be enabled together
4. **Architecture Dependencies**: Options specific to 32-bit or 64-bit

### Example Dependencies

```bash
# APIC support requires SMP
ENABLE_APIC depends on ENABLE_SMP

# PAE only available on 32-bit
ENABLE_PAE depends on BUILD_ARCH=32

# MSI requires both PCI and APIC
ENABLE_MSI depends on ENABLE_PCI,ENABLE_APIC
```

### Validation

The system validates configurations and reports conflicts:

```bash
Configuration validation errors:
  - ENABLE_MSI requires ENABLE_PCI to be enabled
  - ENABLE_PAE requires BUILD_ARCH=32
```

## Integration with Build System

The configuration system integrates seamlessly with the Forest OS build system:

### Workflow

1. **Configure**: Use `./conf.sh` to set options
2. **Generate**: Configuration creates `build-config.mk`  
3. **Build**: Makefile uses generated configuration
4. **Rebuild**: Changes require regeneration

### Generated Files

- **`.forestos_config`**: Human-readable configuration
- **`build-config.mk`**: Build system configuration
- **Feature flags**: Compiler defines for conditional compilation

### Build Integration Example

```bash
# Configure system
./conf.sh

# Configuration is automatically used by build system
make ARCH=64 BUILD_TYPE=release

# Or force regeneration
./conf.sh --generate
make
```

## Extending the Configuration System

### Adding New Options

1. **Define Option**: Add to `CONFIG_DB` array
2. **Add to Menu**: Include in `MENU_STRUCTURE`
3. **Handle Dependencies**: Update dependency tracking
4. **Update Build**: Modify build configuration generation

### Example New Option

```bash
# In conf.sh CONFIG_DB section:
CONFIG_DB[ENABLE_BLUETOOTH]="bool:n:ENABLE_USB:Bluetooth support:Enable Bluetooth wireless communication"

# In MENU_STRUCTURE:
MENU_STRUCTURE[hardware]="...existing...|Bluetooth Support|ENABLE_BLUETOOTH"
```

## Troubleshooting

### Common Issues

**Terminal Too Small**:
```bash
Error: Terminal too small. Minimum size: 80x24
Current size: 70x20
```
Solution: Resize terminal window

**Configuration Conflicts**:
```bash
Configuration validation errors:
  - ENABLE_FEATURE_X requires ENABLE_FEATURE_Y to be enabled
```
Solution: Enable required dependencies or disable conflicting options

**Build Integration Issues**:
```bash
# Regenerate configuration
./conf.sh --generate

# Check generated files
cat build-config.mk
```

### Debug Mode

```bash
# Enable verbose bash debugging
bash -x ./conf.sh

# Check configuration loading
./conf.sh --load .forestos_config
```

## Advanced Features

### Batch Configuration

```bash
# Create configuration scripts
cat > server_config.sh << 'EOF'
#!/bin/bash
./conf.sh --defaults
# Modify specific values in .forestos_config
sed -i 's/CONFIG_ENABLE_GRAPHICS=y/CONFIG_ENABLE_GRAPHICS=n/' .forestos_config
./conf.sh --generate
EOF

chmod +x server_config.sh
./server_config.sh
```

### Configuration Profiles

```bash
# Save profiles
./conf.sh --save desktop_config
./conf.sh --save server_config
./conf.sh --save embedded_config

# Load profiles
./conf.sh --load desktop_config
```

